# healthPool Asseit: app (Expo + NativeWind)

Veja o README na pasta acima para rodar e publicar.

- `npx expo start -c` para desenvolver (precisa do `.env`, copie de `.env.example`).
- `npm run build:web` gera a versão web em `dist/` (o Dockerfile faz isso sozinho).
- Sem login: a tela inicial pede o código de acesso da equipe (`src/access/`).
